mathglyph

Monospace text with a math accent: letters turn into symbols, then settle.

GitHub README

Point at the text, or drag across it, to stir the symbols.

Text and font
Sets the lines and a word map for that language.
One line per row. Wrap words in *stars* to highlight them.
Leave it empty to use a font installed on this device. The server must allow cross-origin requests.

These fonts load from jsDelivr (Fontsource files). The library itself loads no fonts by default. This page also loads a self-hosted subset of Noto Sans Math for the math glyphs.
