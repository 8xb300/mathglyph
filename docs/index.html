mathglyph

GitHub README

Monospace text with a math accent: letters turn into symbols, then settle.

how to use

Point at the text, or drag across it, to wake the symbols. Move away and it goes back to plain. Browse the layouts and effects.

Leave it empty to use a font installed on this device. The server must allow cross-origin requests.

The monospace fonts load from jsDelivr (Fontsource files). The three Hong Kong fonts for Chinese text are small self-hosted subsets. The library itself loads no fonts by default. This page also loads a self-hosted subset of Noto Sans Math for the math glyphs.
